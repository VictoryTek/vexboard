# v0.2.0

## Added

- Quick links can now be organized into groups and reordered by drag-and-drop,
  matching the grouping/reordering support service cards already had. Quick
  link groups are managed independently from service groups (their own
  "Manage Quick Link Groups" modal), and the quick links section gets its own
  A-Z/Group sort toggle alongside the existing services one.

## Fixed

- Systemd/Docker/Podman-discovered service cards now show a latency sparkline
  like remote (URL-probed) services do. Previously, systemd-based probes never
  recorded a latency measurement, so the sparkline's polyline could never be
  drawn for those cards — only the uptime-% text showed. The D-Bus unit-state
  check's round-trip time is now recorded as `latency_ms`, giving every service
  type a consistent card.
- Service cards no longer blink (disappear and reappear) on every probe update.
  The dashboard's card list previously rebuilt and remounted every card on any
  single service's SSE status update, restarting each card's history fetch.
  Each card now updates its own status/latency in place, so only the affected
  card's badge changes.
- Settings page redesigned as a single-column sectioned list (About, Appearance,
  Navigation Sidebar, Service Discovery, User Management), replacing the previous
  multi-column tile grid whose mismatched card heights and missing responsive
  breakpoint made it look disjointed. Also fixed the Add User form fields, which
  referenced a non-existent CSS class and rendered as unstyled white input boxes.
