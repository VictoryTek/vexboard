# v0.2.0

## Fixed

- Systemd/Docker/Podman-discovered service cards now show a latency sparkline
  like remote (URL-probed) services do. Previously, systemd-based probes never
  recorded a latency measurement, so the sparkline's polyline could never be
  drawn for those cards — only the uptime-% text showed. The D-Bus unit-state
  check's round-trip time is now recorded as `latency_ms`, giving every service
  type a consistent card.
- Service cards no longer blink (disappear and reappear) on every probe update.
  The dashboard's card list previously rebuilt and remounted every card on any
  single service's SSE status update, restarting each card's history fetch.
  Each card now updates its own status/latency in place, so only the affected
  card's badge changes.
